# M Math Hogwarts

独立的霍格沃茨算术冒险游戏。纯静态页面，无构建步骤或外部运行依赖。

从录取信开始，选择学院，在魔法世界地图进入霍格沃茨，学习咒语、探索小径、遇见生物，再完成限时计算收集拼图。拼图册、生物图鉴和家长中心是独立界面。当前可玩内容是第一章六关，后续地区保留锁定入口。

## 打开

从仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/playground/m-math-hogwarts/`。部署到现有静态站点后，页面路径为 `/playground/m-math-hogwarts/`。

## 内容

- `index.html`：页面入口。
- `styles.css`：布局、地图、拼图、计时器与报告样式。
- `app.js`：关卡数据、50 题生成、计时、每周奖励与本地存储。
- `game-ui.js`：分院、地图、教学、探索、战斗和结算界面。
- `reports.js`：家长周报、打印和导出。
- `music.js`：内置原声音频、自动播放与答题降音量。
- `reset.js`：清空游戏存档并同步其他标签页。
- `assets/`：六张 AI 生物图片、四学院徽章，以及素材来源与生成提示词。
- `config.example.json`：当前规则示例。运行配置以 `app.js` 为准，该文件不是运行时配置入口。

## 当前规则

固定每轮 50 题，同屏显示当前题与后续四题。答对回车前进，答错留在原题并扣 5 秒。20 以内加减法及九九乘法为 6 分钟，100 以内加减法及加减乘综合为 8 分钟。

限时完成一轮获得一片拼图，每天最多三片，每周十二片完成当前关，下一关下周一开放。未完成的本周拼图下周归零，已完成关卡及历史学习记录保留。

## 本地数据

周进度保存在 localStorage，学习记录与未完成题组保存在 IndexedDB；均使用 `m-math-hogwarts` 命名空间。刷新会继续原倒计时。支持周报、错题本/全部题目打印、CSV/JSON 导出。

原本 `file://` 设计文档、本地 HTTP 预览与正式站点属于不同存储来源，记录不会自动迁移。当前不提供存档导入，请保留旧文档并按需导出旧记录。

## 回归检查

在可用 `playwright` 和 Chrome 的 Node 环境中，先启动上述本地服务器，再运行：

```sh
node playground/m-math-hogwarts/tests/game-flow.cjs
node playground/m-math-hogwarts/tests/progression.cjs
node playground/m-math-hogwarts/tests/music.cjs
node playground/m-math-hogwarts/tests/reset.cjs
```

可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，用 `GAME_URL` 指定测试地址。测试使用独立浏览器上下文，不修改日常浏览器存档。覆盖完整游戏流程、中英文切换、错误扣时与纠正、50 题奖励、存档恢复、每日上限、跨周解锁与重置、超时结算和手机宽度。

## 背景音乐

`music.js` 使用随页面部署的音频资源，默认自动尝试低音量循环播放，答题时音量不高于 8%。浏览器阻止有声自动播放时，第一次普通游戏点击或按键会重试，无需单独点击播放。顶部按钮可随时关闭；题目重绘不重建音频，离开标签页会暂停。

原始音频位于 `assets/hedwigs-theme.mp3`，由用户提供，按原文件复制，未转码或裁剪；网页直接引用该文件，无需联网加载第三方播放器，也无需玩家选择文件。

## 从头测试

打开「家长中心」，点击「清空本地数据并重新开始」，确认后清空本游戏的角色、学院、语言/音量偏好、每周拼图、学习记录与未完成题组，并刷新回初始界面。同源打开的其他游戏标签页会同步刷新，其他小游戏的数据不受影响。此操作无法撤销。
